# Data

The dataset is not included in this repo. It is the Kaggle
[Kobe Bryant Shot Selection](https://www.kaggle.com/c/kobe-bryant-shot-selection/data) data
(30,697 shots, 25 columns, `shot_made_flag` missing for 5,000 rows).

Download `data.csv` (a free Kaggle account is required) and place it in this folder.
Please follow Kaggle's terms of use.
